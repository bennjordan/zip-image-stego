# 🤫 Zip-Image Stego 🤫

![App Screenshot](https://github.com/bennjordan/zip-image-stego/blob/main/screensh0t.png?raw=true)

### Hide files in images that can (usually) survive social media recompression via  [Javid Steganography](https://github.com/Iman/javid-steganography). 


## Installation

#### 1. Install Python 3.
#### 2. [Recommended] Create and launch a virtual environment.
#### 3. Install Requirements

```bash
  pip install -r requirements.txt
```
#### 4. Launch Zip-Image Stego 
Linux

````bash
python app.py
````
Windows PowerShell

````bash
python .\app.py
````
#### 5. Launch WebUI

Go to http://127.0.0.1:5000 in a local browser once instructed in the terminal.
